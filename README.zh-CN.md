# RVC Dataset Studio（RVC 数据集工作台）

这是一个在 Windows 本地运行的 RVC 训练音频准备工具。每个角色项目可接收本地视频、音频和在线视频链接，统一进行音轨提取、语音切分、质量检查、人工审核和分批导出。

## Windows 安装与启动

需要 Windows 10/11、Python 3.11 或 3.12（含 `py` 启动器）、Node.js 22.12 或更高版本，以及 PATH 中的 `ffmpeg` 和 `ffprobe`。使用 `py -0p`、`node --version`、`ffmpeg -version` 和 `ffprobe -version` 检查。

到 [GitHub 发布页](https://github.com/hhsbjbsj/rvc-dataset-studio/releases/latest) 下载 Windows x64 ZIP，解压到剩余空间充足的磁盘，从解压目录打开 `RvcLauncher.exe`。首次打开可点击「初始化环境」，然后点击「启动工作台」。如果关掉了浏览器标签页，回到启动器点「打开工作台」即可。启动器会显示实际地址，默认使用 5173 端口，遇到占用时会自动选择空闲端口。顶部可以换图或恢复默认壁纸。「背景适配」支持铺满裁剪、完整显示和拉伸填满，裁剪时可在预览里拖动图片。左侧齿轮可切换启动器语言和自动检查更新。点击「检查更新」可阅读新版说明，再点「下载并重启更新」在应用内安装。更新源固定为本项目的 GitHub 仓库。安装前请保存编辑，等待处理任务结束。关闭启动器时，可确认停止它启动的服务。

从源码构建启动器需要 .NET 10 SDK。在项目根目录运行 `build-launcher.ps1` 会生成 Windows x64 单文件 EXE。版本号由启动器项目文件管理。准备发布时，在干净的 Git 提交上运行 `package-release.ps1`，会生成含 EXE、源码和已编译网页的 Windows ZIP 及 SHA-256 校验文件。把 ZIP 上传到 GitHub 正式 Release，并填写本次更新说明，启动器就能检查和安装。更新会备份替换的程序文件，安装失败时回滚。项目、音频、导出和设置保存在独立数据目录。新版增加 Python 依赖时，安装完成后会提示初始化环境。

也可以在项目根目录打开 PowerShell，依次运行以下开发命令。

```powershell
powershell -ExecutionPolicy Bypass -File .\setup-rvc.ps1
powershell -ExecutionPolicy Bypass -File .\start-rvc.ps1
```

浏览器打开 [RVC 项目](http://127.0.0.1:5173/rvc)。在启动终端按 Ctrl+C 可停止服务。API 启动日志位于 `voiceforge-backend/tmp/run`。后端默认使用 8001 端口，可在启动前设置 `VOICEFORGE_PORT`。

首次安装需联网拉取 Python 和前端包。安装完成后，本地媒体的识别、切分、审核和导出可以离线完成。首页直接进入 RVC 项目，使用 CPU、WebRTC VAD 和 SQLite 本地队列。首页支持简体中文、英语和日语。角色项目的导出批次会保存在项目内和「历史记录」页。

## 创建角色项目

填写作品、角色、语言和目标分钟数。目标时长用来对照已保留片段的总时长。素材可分批加入，同一项目内会跳过已登记的路径和重复链接。

## 导入 MP4、MKV 或其他视频

1. 在 **导入本地视频** 中选择多个文件或选择文件夹。选择文件夹时可启用 **扫描子文件夹**。也可在文本框每行粘贴一个文件或文件夹的完整路径。
2. FFprobe 会列出音轨编码、采样率、声道和可用的语言标签。多音轨视频可在素材行指定目标音轨。
3. 保持 **自动切分语音** 开启，按需修改最短、最长片段时长。点击 **处理待处理和失败素材**。FFmpeg 只解码选定音轨，工作文件与原素材分开。
4. 在审核列表试听，查看原始路径和原始音轨时间，保留目标角色的片段或剔除误切片段。

## 导入音频

在 **导入本地音频** 选择 WAV、MP3、FLAC、M4A、AAC、OGG、OPUS 等文件或文件夹。长音频可自动切分。已分句的干净音频可关闭自动切分，每个文件作为一个片段，单文件上限为 120 秒。峰值调整默认关闭。

## 搜索和添加在线素材

在 **在线搜索与链接** 中点击 **搜索 B 站**。查询由项目的作品、角色、语言和可选关键词组成。候选列表显示标题、UP 主和时长，可翻页和批量选择。也可粘贴 B 站 b23.tv 短链接、BV/av 视频链接或 YouTube 单视频链接，一行一条。B 站指定分 P 时保留 `?p=2` 之类的页码参数。

素材加入项目后，点击处理按钮，队列调用 yt-dlp 下载并进入相同的处理流程。搜索或下载报错时可分别重试。采集使用你有权处理的素材。

## 混合处理示例

为同一角色创建一个项目。加入一条 B 站视频链接，从 **导入本地视频** 选择一个剧情 MP4 和一个 MKV，再从 **导入本地音频** 加入已有语音。点击处理后可在同一列表查看进度、音轨、来源和错误。任务中断后，重启时会从受影响的素材重新处理。对于处理失败或已取消的素材，也可以单独重试。

## 审核与导出

**试听和审核** 支持逐条试听和批量保留或剔除。质量分数用于辅助判断，列表也显示 SNR 和原始时间范围。

勾选一组片段后，点击 **导出所选片段**，即可把这组片段单独打成 ZIP。勾选跨页保留，导出不会修改审核状态。要分开导出多个角色，可以导出一组后点击 **清除选择**，再勾选下一组。**导出已保留片段** 可打包当前项目中所有标为保留的片段。

要把误切成多段的一句话接回来，勾选相关片段再合并。原片段移入合并缓冲区，确认不需要后可以逐个删除或一键清空。打开合并结果的波形编辑器，可在同一条波形上建立多个选区，分别拖动边界和试听。保存时每个选区会成为一条独立片段，试听速度不会写入输出。

波形编辑器获得焦点时，可用键盘操作：

| 按键 | 操作 |
| --- | --- |
| ↑ / ↓ | 切换选区。循环播放时从新选区开头继续；暂停时只切换。 |
| ← / → | 移动起点，每次 0.01 秒。按住 Shift 则移动终点。 |
| 空格 | 从当前选区开始循环，或暂停、从暂停处继续。试听支持 1、0.75、0.5、0.25 倍速。 |
| Delete（含小键盘 Del） | 移除当前选区，循环中自动接播下一段。 |
| Ctrl+Z / Ctrl+Y | 撤销或重做选区的移除。 |
| Ctrl+S | 一次保存所有剩余选区。 |

每次 ZIP 导出都会留下独立记录。重开软件后，在项目的「导出历史」或顶部「历史记录」页可以重新下载。已有 MP3 等音频也可以先在「音频转换」页统一格式和音量，再把转换结果直接导入现有或新建的角色项目。

导出支持 16、22.05、24、32、40、44.1 和 48 kHz。导出目录和 ZIP 都含有 `wavs`，其中每个文件为单声道、16-bit PCM WAV。将 `wavs` 的路径交给 RVC 的预处理步骤。三个 JSON 文件分别记录数据集和片段、素材来源及质量检查结果。

## 磁盘位置

- `voiceforge-backend/venv` 与 `frontend/node_modules` 保存依赖。
- `voiceforge-backend/voiceforge.db` 保存项目、队列和审核状态。
- `voiceforge-backend/tmp/rvc` 保存项目工作文件和试听片段。完整音轨的解码中间文件在本次处理结束后清理。
- `voiceforge-backend/static/outputs/rvc` 保存各次导出的 WAV 目录、清单和 ZIP。可在导出结果中查看具体目录。

这些路径默认位于仓库所在磁盘。48 kHz 单声道 PCM 每小时约 330 MiB。开启切分时还有 16 kHz 工作音轨，导出会额外保存 WAV 和 ZIP 两份。处理前会估算所需空间，并保留 1 GiB 余量。

## 测试与当前范围

在 `voiceforge-backend` 下运行以下命令。

```powershell
.\venv\Scripts\python.exe -m pytest tests/test_rvc_projects.py
```

媒体测试在 Windows 用系统语音合成器生成样本，验证多音轨 MP4、MKV、中文路径、MP3/WAV/FLAC、原文件哈希、混合来源、音频试听、审核和 40 kHz 导出。测试中的 B 站搜索和下载有模拟数据，以便离线复现。

当前重复检测基于标准化解码后的 PCM 哈希。重新编码或边界改变后的相似语音仍需要人工审核。说话者由用户试听确认。当前版本不做声纹匹配、背景音乐或音效分离，也不训练 RVC 模型。
